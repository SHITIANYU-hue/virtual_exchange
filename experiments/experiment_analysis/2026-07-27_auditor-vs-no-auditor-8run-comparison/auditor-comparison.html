World B's late-run audit collapse, rep1 vs rep2

Flag rate by thirds of the run. Both World B reps decline monotonically into the final third; neither World A rep does — this replicates the original report's finding and looks like the most robust category-level result in the whole dataset.

Data quality caveats

World B's no-auditor pair is not a clean replicate set

B-noaud-cloud1 has an incomplete action log (~578 of an expected 720 action files, and no errors/ directory to explain the gap). B-noaud-local has the lowest dispersion of any run (32.6) despite complete logs — an outcome outside the range of every other run. Together these mean the "auditor decreases World B dispersion" reading in the headline stats above rests on one incomplete-log run and one statistically surprising run, not two clean independent replicates.

No recurrence of the earlier parse-crash bug

Checked every errors/ file across all 8 runs for the 'str' object has no attribute 'get' signature (fixed in commit 0954878) — zero matches anywhere.
