World A vs World B — 72-Cycle Historical Replay Comparison

Two identical 10-agent adversarial-exchange experiments (same agents, same starting balances, same model, same audit configuration, full hard-reset before each) — the only intentional difference is which real historical 72-hour BTC/ETH/SOL price path was replayed to the agents.

Live interactive version: claude.ai/code/artifact/f10819d5-34de-459d-8ad6-35d1c668c9bb

Double-blind design. One world replays a real historical bull market, the other a real historical bear/crash — but which is which was never revealed during this analysis, and the mapping file was never opened. Everything below refers only to the neutral labels World A and World B. The reveal is a deliberate manual step the researcher takes after analysis is complete.

Confounds worth flagging before drawing conclusions

Most extreme single-cycle swings are a mark-to-market artifact, not real P&L — in both worlds

Agents launch thinly-traded meme tokens (World A: MOON; World B: SURGE, FAIRPLAY, NEXUS, COMPOUND, MOONSHOT, VORTEX, CULT). With near-zero pool liquidity, the pool-implied price used to value a held position swings wildly cycle to cycle even with zero trading activity. Example: AlphaBot's FAIRPLAY balance in World B was frozen across cycles 14→17, yet its reported portfolio value swung $10,978 → $209,068 → $10,963 → $212,419 — an artifact of the token, not a trade. World B had more of these tokens in play, which likely amplifies its wider return dispersion independent of the underlying BTC/ETH/SOL path.

BearKing's World B collapse traces to one malformed trade

Cycle 4: a v3_swap with an amount field of ~1.6 quadrillion units (vs. ~40k the cycle before) — almost certainly a hallucinated/malformed LLM output — was only flagged (not blocked) by the auditor and executed, crashing the portfolio 88.8% in one cycle ($90,292 → $10,110). BearKing spent 62 of the next 68 cycles below $6,000, ending at $4,580 (−90.8%). This is a real, not mark-to-market, capital loss.

Error rates were modest and roughly comparable

17 error files in World A vs 11 in World B (out of 720 agent-cycles each) — mostly malformed LLM JSON output. Not large enough to be strong evidence of an infrastructure confound, but noted for completeness.
